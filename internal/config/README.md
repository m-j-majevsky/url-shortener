# internal/config

В этом пакете хранятся конфигурации приложения.

Загрузка конфигурации реализована из двух источников: переменных окружения и флагов командной строки.

## Два слоя

- **Слой чтения** (`readApplicationConfig`) — считывает значения из env и флагов, не валидируя их содержимое. Единственное исключение — `SAVE_STATE_INTERVAL`, который требует интерпретации как `time.Duration`.
- **Слой валидации** (`validateApplicationConfig`) — проверяет, что обязательные параметры непусты, и возвращает итоговую структуру или ошибку.

Такое разделение позволяет менять логику валидации, не затрагивая слой чтения, и наоборот.

## Приоритеты источников (от низшего к высшему)

1. Жёстко заданные значения по умолчанию.
2. Флаги командной строки — парсятся со своими дефолтами.
3. Переменные окружения — перекрывают флаги.

Приоритет env над флагами — **ограничение проекта**. Пустое значение переменной окружения считается отсутствующей переменной: иначе «пустая» env молча затирала бы явно переданные оператором флаги.

Обязательные параметры: `SERVER_ADDRESS`/`-a`, `BASE_URL`/`-b`, `LOG_LEVEL`/`-l`, `SIGNING_KEY` (только env). При пустом `SIGNING_KEY` конфиг возвращает `ErrEmptySigningKey`; подстановку хардкода делает `cmd/shortener`.
